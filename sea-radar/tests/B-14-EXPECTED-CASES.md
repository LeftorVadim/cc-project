# B-14 — таблица входных данных и ожидаемых результатов

Ожидания ниже утверждены по согласованным значениям `../../descr/SPRINT-03.md` до написания assertions. Они записаны явно и не вычисляются вызовом `positionReportToVessel`. Базовый вход — `../data/samples/position-report.sample.json`; изменения к нему в тестах являются синтетическими вариантами.

| № | Сценарий | Вход относительно образца | Ожидаемый результат | Что проверяется |
|---:|---|---|---|---|
| 1 | Корректное сообщение | Образец без изменений | `{ id: "123456789", name: "TRAINING VESSEL", lat: 50.95, lon: 1.42, speedKnots: 12.4, courseDeg: 274.6, timestamp: "2026-11-12T12:00:00.123Z", source: "aisstream" }` | Все поля модели и преобразование времени |
| 2 | Название отсутствует | Удалить `MetaData.ShipName` | Судно сохраняется; `name: null` | Отсутствие имени не отбрасывает валидную позицию |
| 3 | Название состоит из пробелов | `MetaData.ShipName = "   "` | Судно сохраняется; `name: null` | Пустое после обработки имя становится `null` |
| 4 | Нулевая скорость | `Message.PositionReport.Sog = 0` | `speedKnots: 0` | Ноль не подменяется на `null` |
| 5 | Скорость выше диапазона | `Sog = 102.3` | `speedKnots: null` | Недопустимая скорость неизвестна |
| 6 | Отрицательная скорость | `Sog = -1` | `speedKnots: null` | Недопустимая скорость неизвестна |
| 7 | Скорость отсутствует | Удалить `Sog` | `speedKnots: null` | Неизвестное поле не становится нулём |
| 8 | Курс 360° | `Cog = 360` | `courseDeg: null` | Значение вне допустимого диапазона неизвестно |
| 9 | Координаты 91/181 | `Latitude = 91`, `Longitude = 181` | Результат `null`; объект судна отсутствует, в том числе в `(0, 0)` | Некорректная позиция отбрасывается |
| 10 | Координаты вне диапазона | `Latitude = 95`, `Longitude = -200` | Результат `null`; объекта в `(0, 0)` нет | Отбрасываются обе недопустимые координаты |
| 11 | Координата строкой | `Latitude = "50.95"` | Результат `null` | Строка не принимается за координату |
| 12 | MMSI отсутствует | Удалить `MetaData.MMSI` | Результат `null` | Без идентификатора позиция отбрасывается |
| 13 | MMSI пустой | `MetaData.MMSI = ""` | Результат `null` | Пустой идентификатор недопустим |
| 14 | Время непарсимое | `MetaData.time_utc = "not-a-timestamp"` | Результат `null` | Без валидного времени позиция отбрасывается |

Тесты запускаются без браузера командой `npm run test:node` из каталога `sea-radar`. Тестовые данные и ожидаемые значения независимы: assertions сравнивают результат с литералами из этой таблицы, а не с повторным вызовом проверяемой функции.
